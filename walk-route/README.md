# מסלול הליכה מהירה 🚶‍♀️

אפליקציה לאנדרואיד ולאייפון (Expo / React Native) שבונה מסלול הליכה באורך שמבקשים, לפי מהירות ממוצעת שמגדירים.

## מה היא עושה
- **מסלול מעגלי** – יוצאים מהכתובת (או מהמיקום הנוכחי 📍) וחוזרים אליה, באורך המבוקש.
- **מכתובת לכתובת** – מסלול מנקודה A לנקודה B שמתארך בעיקוף כדי להגיע למספר הק"מ המבוקש.
- **יעד לפי ק"מ או לפי זמן** – למשל "45 דקות ב-6 קמ"ש" ← מסלול של 4.5 ק"מ.
- **מפה** עם המסלול, מרחק, זמן משוער וקצב (דק׳/ק"מ).
- **"מסלול אחר"** – מגריל מסלול חדש באותו אורך.
- **פתיחה בגוגל מפות** לניווט קולי.
- **מעקב בזמן אמת** – זמן, מרחק, מהירות וקצב נוכחיים וממוצעים, כמה מטרים/שניות לפני או אחרי הקצב, התראה על סטייה מהמסלול. המסך נשאר דלוק בזמן ההליכה.
- המהירות וההגדרות נשמרות לפעם הבאה.

## איך מריצים על הטלפון
1. מתקינים את האפליקציה **Expo Go** מחנות האפליקציות (אנדרואיד או אייפון).
2. במחשב (צריך Node.js):
   ```bash
   cd walk-route
   npm install
   npx expo start
   ```
3. סורקים את קוד ה-QR שמופיע: באנדרואיד מתוך Expo Go, באייפון עם המצלמה.

### התקנה קבועה (בלי Expo Go)
- **אנדרואיד**: `npx eas-cli@latest build -p android --profile preview` יוצר קובץ APK להתקנה ישירה (צריך חשבון Expo חינמי).
- **אייפון**: דורש חשבון Apple Developer; עד אז אפשר להשתמש ב-Expo Go.

## שירותים חיצוניים (חינמיים, בלי מפתח API)
- ניתוב הולכי רגל: [Valhalla](https://valhalla1.openstreetmap.de) של OpenStreetMap
- חיפוש כתובות: [Nominatim](https://nominatim.openstreetmap.org) (עם גיבוי של חיפוש הכתובות של הטלפון)
- מפה: Leaflet עם אריחי CARTO / OpenStreetMap

אפשר גם להקליד קואורדינטות במקום כתובת, למשל `32.0853, 34.7818`.

## מבנה הקוד
- `App.tsx` – המסכים (תכנון / הליכה)
- `src/routing.ts` – חיפוש כתובות ובניית מסלול באורך היעד
- `src/useWalkTracker.ts` – מעקב GPS בזמן אמת
- `src/RouteMap.tsx` – המפה
- `src/geo.ts` – חישובי מרחקים
